Licasa 0.1.0 is the first Ubuntu package of the desktop image viewer and editor.

### Download

Download both `licasa_0.1.0-1_amd64.deb` and `licasa_0.1.0-1_amd64.deb.sha256` from this release. The package targets **Ubuntu 24.04 on amd64**.

### Included

- Fullscreen and floating image viewing, with editing tools.
- JPEG, PNG, TIFF, WebP, HEIC/HEIF, JPEG XL, AVIF, JPEG 2000, RAW preview, and animated APNG readers.
- Motion Photo playback and the private codec libraries needed by the package.

### Verify and install

Run these commands in the folder containing both downloaded files:

```sh
sha256sum -c licasa_0.1.0-1_amd64.deb.sha256
sudo apt install ./licasa_0.1.0-1_amd64.deb
```

The release workflow builds the attached package from the `v0.1.0` tag, checks its SHA-256, and tests installation and image decoding in a clean Ubuntu 24.04 environment before publication.
