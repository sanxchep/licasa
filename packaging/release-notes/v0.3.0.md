Licasa 0.3.0 makes browsing large photos more responsive. This release includes an Ubuntu 24.04 `.deb` for amd64 and a Snap beta built by Snapcraft's hosted service.

### Install the Snap beta

The Snap's per-user background service currently needs Snapd's experimental user-daemons setting:

```sh
sudo snap set system experimental.user-daemons=true
sudo snap install licasa --beta
```

### Download the Debian package

Download `licasa_0.3.0-1_amd64.deb` and `licasa_0.3.0-1_amd64.deb.sha256` from this release. The package targets **Ubuntu 24.04 on amd64**.

Run these commands in the folder containing both files:

```sh
sha256sum -c licasa_0.3.0-1_amd64.deb.sha256
sudo apt install ./licasa_0.3.0-1_amd64.deb
```

### Included

- Keep nearby, reduced-size previews in a bounded memory cache for faster keyboard browsing.
- Show a quick preview while a large JPEG, TIFF, or camera RAW image finishes loading.
- Let navigation move on from a large image without waiting for its full-resolution decode.
- Make local development installs restart a running older copy.
