Licasa 0.1.1 adds a Snap beta release and an updated Ubuntu 24.04 `.deb` package for amd64.

### Install the Snap beta

```sh
sudo snap install licasa --beta
```

### Download the Debian package

Download both `licasa_0.1.1-1_amd64.deb` and `licasa_0.1.1-1_amd64.deb.sha256` from this release. The package targets **Ubuntu 24.04 on amd64**.

Run these commands in the folder containing both downloaded files:

```sh
sha256sum -c licasa_0.1.1-1_amd64.deb.sha256
sudo apt install ./licasa_0.1.1-1_amd64.deb
```

### Included

- A strictly confined Snap with image viewing, editing, and the packaged image codecs.
- Smoother zooming in floating mode.
