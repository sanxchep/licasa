# Licasa 0.5.1 release notes

Licasa 0.5.1 improves RAW image handling and cleans up the Linux package builds. It includes the viewer and AppImage, Debian package, and Snap installation options introduced in 0.5.0.

### Fixes

- Check truncated dark-frame input before LibRaw reads it, and format TIFF dates safely. These changes make malformed RAW files less likely to interrupt viewing.
- Remove unused build options and packaging warnings, and update maintained GitHub Actions used to qualify release packages.
- Adjust Snapcraft library lint settings for bundled runtime libraries.

### Downloads

- `Licasa-0.5.1-x86_64.AppImage` and `install-licasa-appimage.sh`: install for your user on recent x86-64 Linux desktops. The package uses Ubuntu 24.04 as its minimum Linux library baseline.
- `licasa_0.5.1-1_amd64.deb`: install on Ubuntu 24.04 amd64 with `sudo apt install ./licasa_0.5.1-1_amd64.deb`.
- Snap Store beta: install with `sudo snap install licasa --beta`, or refresh an existing installation with `sudo snap refresh licasa --beta`.
- `licasa_0.5.1_amd64.snap`: available from GitHub with a SHA-256 checksum for direct installation. Direct installations do not follow Store updates.

Background startup remains optional. Turn on **Background process** in Settings if you want the viewer ready after closing and at your next desktop login.
