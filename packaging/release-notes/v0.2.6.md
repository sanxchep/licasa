Licasa 0.2.6 improves editing and image browsing transitions. This release includes an Ubuntu 24.04 `.deb` for amd64 and a Snap beta built by Snapcraft's hosted service.

### Install the Snap beta

The Snap's per-user background service currently needs Snapd's experimental user-daemons setting:

```sh
sudo snap set system experimental.user-daemons=true
sudo snap install licasa --beta
```

### Download the Debian package

Download `licasa_0.2.6-1_amd64.deb` and `licasa_0.2.6-1_amd64.deb.sha256` from this release. The package targets **Ubuntu 24.04 on amd64**.

Run these commands in the folder containing both files:

```sh
sha256sum -c licasa_0.2.6-1_amd64.deb.sha256
sudo apt install ./licasa_0.2.6-1_amd64.deb
```

### Included

- Keep the current photo steady while an edited or adjacent image loads, then fade to the ready replacement without stretching the outgoing photo.
- Fit photos beside the editor panel when it opens or changes tools, with smoother panel and image motion.
- Add the installed version and release date to Settings, plus a background-service status indicator in the Snap.
- Improve keyboard focus and original-image comparison in the editor, and make the empty state usable in smaller windows.
