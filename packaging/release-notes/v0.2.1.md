Licasa 0.2.1 updates image browsing, keyboard controls, and background mode. This release includes an Ubuntu 24.04 `.deb` for amd64 and a Snap beta.

### Install the Snap beta

The Snap's per-user background service currently needs Snapd's experimental user-daemons setting:

```sh
sudo snap set system experimental.user-daemons=true
sudo snap install licasa --beta
```

### Download the Debian package

Download `licasa_0.2.1-1_amd64.deb` and `licasa_0.2.1-1_amd64.deb.sha256` from this release. The package targets **Ubuntu 24.04 on amd64**.

Run these commands in the folder containing both files:

```sh
sha256sum -c licasa_0.2.1-1_amd64.deb.sha256
sudo apt install ./licasa_0.2.1-1_amd64.deb
```

### Included

- Browse adjacent images in fullscreen view and use keyboard shortcuts for viewing, editing, menus, and notification history.
- Start the background process at login on native installs or through the Snap's per-user service.
- Clear failed or cancelled image previews from the pending decode registry and improve image-opening feedback.
- Build the Snap from source with Snapcraft's hosted build service, then test its Store revision before beta promotion and GitHub `.deb` publication.
