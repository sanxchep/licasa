# Licasa 0.9.8 release notes

## Image opening and decoding

- Improved repeated file opens by forwarding eligible requests to the running
  viewer before initializing the Qt GUI. Executable identity checks also use
  faster SHA-256 verification where OpenSSL is available.
- Improved first previews of large TIFF and BigTIFF images by sampling the data
  needed for the preview. The full-detail decoder still loads the complete image.
- Reduced temporary allocations when the bundled SVG renderer opens SVG or SVGZ
  files containing embedded Base64 images.
- Fixed XBM decoding in the AppImage when a hexadecimal token spans two reads.

## Viewer and settings

- Added a **Show GNOME top bar** setting on GNOME Wayland. Turn it on to use the
  fullscreen viewer layout in a maximized window and adjust background opacity.
  The opacity control explains when native Wayland fullscreen prevents adjustment.
- Fixed manually typed destinations in Qt fallback save and export dialogs.
- Shortened the **Background process** description in English and Swedish.

## Packaging

- Fixed AppImage root permissions so a regular user can start the mounted
  application. Added checks for archive permissions and the pinned runtime inputs.

## Opening performance compared with 0.9.7

With Licasa already running, Full HD JPEG and PNG photos opened **23–28% sooner at p95** from Nautilus. With the viewer ready at login, median time to the photo fell from **489 to 358 ms for JPEG** and **483 to 358 ms for PNG**. Cold starts showed a different result. The 100 MP PNG median rose from **824 to 849 ms**, exceeding its regression limit by 0.11 ms.

The comparison timed real input to the first correct photo visible in a compositor capture on physical GNOME Wayland at 1920 × 1080 with normal animations. Across three fixtures and five opening routes, **493 of 500 scheduled pairs** had valid results for both versions. Of 960 planned format, size and route combinations, 15 were scored. The remaining 945 include other formats, chooser confirmation and rapid transitions.
