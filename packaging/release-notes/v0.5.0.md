# Licasa 0.5.0 release notes

Licasa 0.5.0 adds a portable AppImage alongside the Ubuntu `.deb` and Snap beta. It also makes rapid arrow-key browsing of large mixed photo folders smoother and stops queued browsing steps when the key is released.

### Downloads

- `Licasa-0.5.0-x86_64.AppImage` and `install-licasa-appimage.sh`: install for your user without FUSE, administrator access, or separate Qt and codecs. The script extracts the package once, adds an application-menu launcher, and registers image types for Open With and default-app selection. The package uses Ubuntu 24.04 as its minimum Linux library baseline.
- `licasa_0.5.0-1_amd64.deb`: install with `sudo apt install ./licasa_0.5.0-1_amd64.deb` on Ubuntu 24.04 amd64. APT installs the Qt/QML dependencies.
- Snap beta: install with `sudo snap install licasa --beta`. This version needs no experimental Snapd setting. Licasa opens on demand, so the first launch may take longer without a running background process.

Background startup is now optional for all three packages. Turn on **Background process** in Settings to keep the viewer ready after closing and start it after your next desktop login. The option uses a per-user login entry, requires no administrator password, and can be turned off in the same place. A new installation does not start a background process until you opt in. Warnings and errors are kept in a small, private per-user log for troubleshooting.

The AppImage, installer script, and `.deb` each have a SHA-256 checksum file. The release workflow checks a fresh Ubuntu 24.04 build and source tests, clean Ubuntu `.deb` installation, FUSE-free AppImage installation on Ubuntu and Fedora, image decoding without Qt installed, and Arch X11/Wayland launches. The Arch check also verifies that the packaged libraries resolve there. A native KDE Plasma session still needs hands-on testing before calling it qualified.

### Browsing and format changes

- Arrow-key browsing now paints intermediate photos more reliably during fast key repeats and settles on a full-detail image after the key is released.
- HEIF and AVIF format probing uses container signatures more carefully, reducing false matches with other files.
