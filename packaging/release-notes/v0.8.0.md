## Other changes

- AppImage updates restore the application, icon and launcher together on failure.
- Recorded XDG paths make uninstall reliable; installer locking, support reports,
  private logs and desktop-entry escaping improve installation and recovery.
- Fixed Wayland helper-library loading and NVIDIA black windows through automatic
  GLES selection; explicit graphics choices remain respected.
- Deterministic private dav1d 1.5.4 selection and dependency scans before test tools.
- Fixed HEIF worker-context lifetime and paused-seek frame boundaries.
- Offline dependency caches, deterministic RawSpeed3 inputs, exact build caches
  and checked Debian-payload reuse for Snap.
- Independent capture calibration, a test-only Weston capture fix and correct
  reporting of unavailable GPU checks as skipped.

## Known limits

- Some controls slowed: QOI preview **+2.9%**, tone-only **+2.6–2.9%**;
  some QOI/APNG p95 timings also increased.
- Opening gates: **15/17**. JPEG p95 **130.875 → 144.772 ms**, exceeding the
  **140.875 ms** limit.
- AMD and native Fedora/Arch hardware desktops remain untested.
